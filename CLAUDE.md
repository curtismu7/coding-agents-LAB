# coding-agents-LAB

Demo-tier standalone app: Ping "Coding Agents" release claims (deck slide 49, release 2026-11-02): inspection inside Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot and Antigravity through each agent's own hook interface. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7150). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app; scripts). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7150 docker compose up --build -d`. Node 26 only.
- Modes: **Mock** (default) = a table (`server/src/mockTable.json`, generated by `npm run mock-table` from the engine; a doctor check and a test fail on drift). **Live** = the real hook script `hooks/lab-hook.mjs` spawned per evaluation: agent JSON on stdin, POST over loopback to `/api/hook`, native answer on stdout. Both loopback-only, zero outbound (netguard + a test).
- Core: `server/src/agents.js` (six agents: managed paths, hook events, request and NATIVE response shapes, each tagged documented or illustrative), `detect.js` (deterministic rules), `codingConfig.js` (CodingAgent config validation and generated TEXT), `evaluation.js`, `service.js`, `app.js`. Diagrams: `server/diagrams/*.json` (diagram-studio/1, loaded by name).
- Rules that bite: the lab NEVER writes any agent configuration or settings file anywhere (tests pin no filesystem write in the server or hook); never state an unverified path or shape as fact (tag it illustrative); generated config is text only; only `.example`/`.invalid` hosts; ports 7150-7199; the gateway app is always "P1 Privilege Agent App"; the mock credential is built at run time; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only (`bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`).
- Field names Enabled, FailClosed, Agents, Gateways (AIGuard, AIIntent, Behaviour carried, not interpreted) come from the console swagger of 2026-10-31, schema only. Everything else (rules, reason codes, effects, the mock certificate format, fallbacks) is lab-invented and tagged so.
- Settings: one shared file `~/Development/.env` (mode 600, `STANDALONE_ENV` overrides), parsed with `util.parseEnv` in `server/src/settings.js`; this lab takes only `CODING_AGENTS_LAB_MODE`, nothing else enters the environment.
- Never echo a credential typed in Live mode. Masking is the family's shared masker: `server/src/shared/{mask,hygiene}.js` are copied unchanged from shared-masker 1.4.0 (9bc664a; refresh by copying again, never edit), `server/src/mask.js` is the adapter (plain `[masked]` marks, opaque only for lab-generated values of an exact shape), `detect.js` findSecrets asks the same masker. Every `res.json` goes through `maskDeep` (values and keys) except scripted scenarios and the story/diagram/sources/info lab data; audit and gaps are masked at write; an MCP call's arguments are shown as names and types only. The edge follows the shared Express recipe (415, one route table for 405, page shell for page addresses only, `bad_workspace` before any state, fixed-code error handler). Tests: `server/test/corpus.test.js` (the shared corpora through the adapter), `corpus-sweep.test.js` (the corpus into every input of every endpoint of a real server), `named-leaks.test.js`, `edge.test.js`, `sweep.test.js`. Run check-drift, check-css and conformance by hand; the hook is loopback-only, refuses redirects and has its own netguard.
